# Features and verified scope

## Implemented in this source package
- Minimal chat home and separate animated voice-chat screen.
- Text chat UI and local browser history.
- Adam/Kajal switch.
- Browser speech recognition/synthesis integration where supported.
- Express API routes for Gemini, OpenAI, Anthropic and DeepSeek text chat.
- Provider runtime-key configuration endpoint.
- Android permission/accessibility starter files and setup documentation.

## Not implemented / requires additional work
- Full-duplex Gemini Live audio streaming.
- Native Android APK build/signing and complete Android UI.
- Functional device-wide accessibility automation.
- Binary file upload and document/image understanding pipeline.
- Direct Google account OAuth, Google Search connector, calendar/contact integrations.
- Social app upload automation, publishing workflows and confirmation UI.
- Full website/app build pipeline, remote execution, database provisioning and APK/AAB generation.

No feature should be represented as working until its native integration and end-to-end tests pass.
